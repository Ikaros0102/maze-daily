## ✨ Особенности

- 🗓️ **Ежедневный уровень:** Новый лабиринт генерируется ровно в полночь по локальному времени пользователя.
- 🔒 **Детерминированный сид:** У всех игроков в один и тот же день генерируется абсолютно одинаковый лабиринт и модификатор (на базе PRNG Mulberry32 и независимых потоков случайности).
- ⏱️ **Тайм-сплиты:** Отсечки времени на 25%, 50%, 75% и финише со сравнением с личным рекордом (Live Delta `+/-`).
- 🌪️ **Ежедневные модификаторы:** 
  - 🌫️ *Туман войны* (динамическая видимость)
  - 🚪 *Ключ и Ворота* (поиск ключа в тупиках для открытия выхода)
  - 🌀 *Порталы* (телепортация между коридорами)
  - 🔄 *Инверсия* (инвертированное управление)
  - 🏁 *Фейковые выходы* (поиск истинного финиша среди ложных)
  - 🌊 *Живые стены* (органическая геометрия грота)
- 📱 **Мультиплатформенность:** Полноценная поддержка ПК (WASD / Стрелки / любая языковая раскладка) и мобильных устройств (плавный виртуальный джойстик).
- 📊 **Локальная статистика:** Запись трека движения светлячка (Replay) и сохранение истории за 30 дней в `localStorage`.

---

## 🛠️ Стек технологий

- **Фреймворк:** React 19 (TypeScript)
- **Сборщик:** Vite
- **Графика:** HTML5 Canvas 2D (60–120 FPS, непрерывная физика скольжения вдоль стен)
- **Иконки:** Lucide React
- **Эффекты:** Canvas Confetti
