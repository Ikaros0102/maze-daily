# 🌀 Maze Daily

[English Version](README.md) | **Русская версия**

[🎮 Играть онлайн](https://Ikaros0102.github.io/maze-daily/)

---

**Maze Daily** — это минималистичная и динамичная браузерная игра в жанре лабиринта с синхронизированной ежедневной генерацией, расширенной физикой движения и передовой модульной системой доступности для игроков с ограниченными возможностями (включая управление головой и полноценную звуковую навигацию для незрячих).

---

## ✨ Основные особенности

- 🗓️ **Ежедневный уровень:** Новый уникальный лабиринт генерируется ровно в полночь по локальному времени пользователя.
- 🔒 **Детерминированный сид:** У всех игроков по всему миру в один и тот же день генерируется абсолютно одинаковая конфигурация лабиринта и модификатор (на базе PRNG Mulberry32 и независимых потоков случайности).
- ⏱️ **Сплиты:** Промежуточные отсечки времени на 25%, 50%, 75% и на финише с расчётом дельты к личному рекорду в реальном времени (Live Delta `+/-`).
- 🌪️ **Ежедневные модификаторы:** 
  - 🌫️ *Туман войны (Fog of War)* — динамический радиус видимости вокруг светлячка.
  - 🗝️ *Ключ и Ворота (Key & Gate)* — поиск ключа в тупиках лабиринта для открытия запертых ворот к выходу.
  - 🌀 *Порталы (Portals)* — парные червоточины для мгновенной телепортации между удалёнными коридорами.
  - 🔄 *Инверсия (Inversion)* — перевёрнутые оси управления для проверки координации.
  - 🏁 *Фейковые выходы (Fake Exits)* — поиск истинного портала среди ложных финишей.
  - 🌊 *Живые стены (Living Walls)* — органическая геометрия природного грота.
- 📱 **Кроссплатформенное управление:**
  - ПК: Клавиатура (`WASD`, стрелки, поддержка любых языковых раскладок).
  - Сенсорные экраны: Виртуальный аналоговый джойстик с динамическим центрированием под палец.
- 📊 **Локальная статистика и Replay:** Сохранение истории забегов за 30 дней, анализ темпа, визуализация пройденной траектории светлячка на карте.
- 🌐 **Мультиязычность (i18n):** Интерфейс полностью переведён на 8 языков: английский, русский, испанский, китайский, японский, немецкий, турецкий и португальский.

## ♿ Модульная система доступности (Accessibility)

Игра разработана с упором на инклюзивность и содержит две независимые системы вспомогательного управления, загружаемые по требованию:

### 👤 1. Управление движением головы (Head Tracking)
- **Технология:** На базе нейросетевой модели `@mediapipe/tasks-vision` (FaceLandmarker).
- **Калибровка:** Интерактивное 3-секундное окно центрирования нейтрального положения головы.
- **Фильтрация тремора:** Встроенная 5%-я мёртвая зона (Deadzone) отсекает естественные микроколебания шеи.
- **Векторная тяга:** Вектор смещения носа напрямую управляет движением светлячка по лабиринту без использования рук.
- **Безопасность:** Отказ в доступе к камере или отсутствие вебкамеры корректно обрабатывается локализованным диалоговым окном без сбоев игры.

### 🎧 2. Пространственная звуковая навигация (Audio Navigation & Blind Gaming)
Полноценный аудио-движок на Web Audio API, позволяющий проходить лабиринт вслепую только по звуку:
- **Пространственное стереопанорамирование (BFS Spatial Panning):** Звучание музыки и навигационного маяка непрерывно позиционируется в стереополе (`-1.0` ... `+1.0`) в сторону следующего шага кратчайшего пути к цели.
- **Механика «Горячо — Холодно» (Proximity Attenuation):**
  - При движении к цели громкость поддерживается на уровне 100%.
  - При ошибочном шаге в тупик звук плавно затухает на 25% за каждый шаг отдаления (вплоть до 30%), сигнализируя о неверной траектории.
  - При возвращении на правильный маршрут громкость мгновенно восстанавливается до 100%.
- **Контрастные мелодические жесты направления:**
  - Шаг **ВВЕРХ**: короткий восходящий двухтоновый импульс (650 Гц $\to$ 880 Гц, жест «подъёма» ↗).
  - Шаг **ВНИЗ**: нисходящий двухтоновый басовый импульс (440 Гц $\to$ 260 Гц, жест «спуска» ↘).
  - Шаг **НАЗАД / тупик**: мягкое приглушение частот через 600 Гц Lowpass-фильтр.
- **Тактильная и звуковая обратная связь при ударе о стены:** Синтезированный мягкий низкочастотный глухой удар (150 Гц $\to$ 40 Гц) + вибрация мобильного устройства (`navigator.vibrate`), защищённые таймером перезарядки ($\ge$ 280 мс) от паразитного дребезга.
- **Двухфазная навигация в режиме «Ключ и Ворота»:**
  - Пока ключ не собран, звуковой маяк ведёт игрока к ключу в обход запертых ворот.
  - В момент взятия ключа проигрывается 4-нотный восходящий арпеджио-перезвон (C5 $\to$ E5 $\to$ G5 $\to$ C6), фоновая музыка мягко приглушается, а навигационный вектор мгновенно перенаправляется на выход.
  - Музыкальные стемы строго привязаны к проценту прохождения контрольных точек (до 25% — только Stem 1, 25–50% — Stems 1 и 2, и т.д.).
- **Динамические аудио-паки (Sound Sets):**
  - Доступны 4 тематических саундтрека: *Classic*, *Organic*, *Synth*, *Clockwork*.
  - Бесшовное переключение на лету с 0.5-секундным кроссфейдом.
  - Фоновое кэширование каждого сета в изолированные корзины Cache API (`maze-pack-${packId}-v${version}`).
- **Горячие клавиши управления звуком:** `[` / `]` или `+` / `-` (регулировка с шагом 10%), `M` (быстрое отключение звука) со звуковым подтверждением текущей громкости.
- **Скринридеры (Screen Readers):** Разметка ARIA с живыми оповещениями (`aria-live="polite"`) о событиях игры (подбор ключа, прохождение контрольных точек, финиш) на всех 8 языках.

### 📦 3. Оптимизация и Cache API (10-Day Retention TTL)
- Все тяжёлые модули (MediaPipe vision bundle, звуковые дорожки, аудио-паки) подгружаются асинхронно только при включении соответствующих опций в настройках.
- Начальный размер бандла игры остаётся ультралёгким (< 320 кБ).
- Загруженные модули сохраняются в Cache API. Если пак или модуль не использовался более 10 дней, он автоматически удаляется при старте приложения для экономии памяти устройства (при этом текущий выбранный пак защищён от удаления).

## 🛠️ Стек технологий

- **Фреймворк:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Сборщик:** [Vite](https://vitejs.dev/)
- **Рендеринг:** HTML5 Canvas 2D (плавная физика с субпиксельным скольжением вдоль стен на 60–120 FPS)
- **Звуковой движок:** Web Audio API (процедурный синтез + 4-канальный мультитрековый стем-плеер)
- **Компьютерное зрение:** `@mediapipe/tasks-vision`
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Праздничные эффекты:** [Canvas Confetti](https://www.kirilv.com/canvas-confetti/)

## 🚀 Локальный запуск и разработка

### Требования
- [Node.js](https://nodejs.org/) версии 20 или выше
- Менеджер пакетов `npm`

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Ikaros0102/maze-daily.git
   cd maze-daily
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Откройте появившуюся в терминале ссылку (обычно `http://localhost:5173/`).

### Сборка и проверка качества
- **Сборка проекта для продакшена:**
  ```bash
  npm run build
  ```
- **Проверка линтером (ESLint):**
  ```bash
  npm run lint
  ```
- **Запуск стресс-тестов звуковой навигации и кэширования:**
  ```bash
  node --import ./tests/ts_resolver.mjs tests/audio_nav_key_gate_stress.mjs
  node --import ./tests/ts_resolver.mjs tests/audio_pack_cache_stress.mjs
  node tests/audio_nav_algo_stress.mjs
  ```
- **Генерация MIDI-дорожек для аудио-паков:**
  ```bash
  npm run generate:midi
  npm run generate:midi:organic
  npm run generate:midi:synth
  npm run generate:midi:clockwork
  ```

## 📂 Структура проекта

```text
maze-daily/
├── public/                 # Статические файлы, манифесты и аудиодорожки паков
│   └── audio/packs/        # Аудио-паки (classic, organic, synth, clockwork)
├── src/
│   ├── components/         # React-компоненты интерфейса и модальные окна
│   │   ├── Controls/       # Виртуальный джойстик, кнопки управления
│   │   └── Modals/         # Настройки, калибровка, статистика, загрузка модулей
│   ├── config/             # Конфигурация уровней и манифест аудио-паков
│   ├── core/               # Физика, процедурная генерация лабиринтов, BFS-поиск пути
│   ├── hooks/              # Игровой цикл (RAF), таймеры, контроллеры ввода
│   ├── modules/            # Модули отложенной загрузки (Head Tracking, Audio Nav)
│   │   ├── audioNav/       # Звуковой маяк, стем-плеер, синтезатор коллизий
│   │   └── headTracking/   # Интеграция MediaPipe FaceLandmarker
│   ├── services/           # Сервис moduleLoader с поддержкой Cache API и TTL
│   ├── types/              # Типы TypeScript (состояние игры, настройки, сплиты)
│   └── utils/              # Хранилище (localStorage), i18n локализация на 8 языков
└── tests/                  # Автоматизированные стресс-тесты алгоритмов и звука
```
