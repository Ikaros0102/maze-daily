# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (SPECIFICATION): Daily Maze Speedrun

## 1. Концепция и Архитектура
Браузерная ежедневная игра в стиле Wordle, где цель — пройти лабиринт на время («спидран»).
- **Платформа:** Client-only SPA (GitHub Pages), без бэкенда.
- **Стек:** React (TypeScript) + Vite + HTML5 Canvas 2D для отрисовки поля.
- **Хранилище:** `localStorage` (темы, настройки, статистика, история заездов).

---

## 2. Детерминизм и PRNG (Случайность)
1. **Базовый сид:** Определяется локальной датой устройства пользователя (`YYYY-MM-DD`). 
   - Время берется системное (чтобы новый уровень наступал в полночь пользователя).
2. **Версионирование алгоритма:** `GENERATOR_VERSION = "v1"`.
   - Полный базовый сид: `${GENERATOR_VERSION}|${YYYY-MM-DD}`.
3. **Раздельные потоки PRNG:** Использовать алгоритм Mulberry32. Создаются независимые генераторы:
   - `mazeSeed` = hash(baseSeed + "_maze") -> генерация структуры стен.
   - `effectSeed` = hash(baseSeed + "_effect") -> выбор модификатора дня.
   - `spawnSeed` = hash(baseSeed + "_spawn") -> точки старта, финиша и объектов.

---

## 3. Генерация лабиринта и Тайм-сплиты
1. **Алгоритм:** Идеальный лабиринт без циклов (DFS / Recursive Backtracker) на сетке N x M.
2. **Точки Старта/Финиша:** Находятся алгоритмом Дейкстры/BFS в наиболее удаленных тупиках.
3. **Система Сплитов (Контрольных точек):**
   - На кратчайшем пути от старта к финишу рассчитываются 3 невидимые ключевые клетки: 25%, 50%, 75% пути.
   - При первом пересечении игроком каждой из этих клеток фиксируется время сплита (`performance.now()`).
   - Повторные заходы в эту клетку ивент не вызывают.
   - Сплиты сравниваются с лучшим личным временем игрока за сегодняшний день.



## 4. Конфигурационный файл (`gameConfig.ts`)
Все ключевые балансные параметры должны быть вынесены в конфиг:
```typescript
export const GAME_CONFIG = {
  maze: {
    cols: 30,
    rows: 30,
    wallThicknessRatio: 0.25, // Относительно размера ячейки
  },
  player: {
    baseSpeedCellsPerSecond: 1.0, // Скорость светлячка (клеток в сек)
    sizeRatio: 0.25,              // Диаметр светлячка = 1/4 ячейки
    glowRadiusMultiplier: 2.5,    // Ореол вокруг светлячка
    defaultColor: "#00f0b5",      // Зеленовато-синий дефолтный цвет
  },
  splits: [0.25, 0.5, 0.75],
};

## 5. Физика, Движение и Отрисовка (Canvas 2D) 
1. **Светлячок:** Круг с градиентным свечением (`createRadialGradient`).
2. **Движение:** Непрерывное и плавное (не пошаговое). Координаты игрока — дробные `(x, y)`.
   - Скорость нормирована по `delta time` между кадрами (не зависит от герцовки монитора).
   - AABB или круг-коллайдер со стенами: светлячок не должен проваливаться в стены или застревать на поворотах (добавить легкое скольжение вдоль стен при диагональном зажатии).
3. **Управление:**
   - **ПК:** WASD и Стрелки.
   - **Мобилки:** Лаконичный виртуальный полупрозрачный джойстик/D-Pad в нижней зоне экрана.
   - Предотвратить нативный зум/скролл (`touch-action: none`).

---

## 6. Локализация (i18n) и Темы
1. **Языки:** Русский (RU) и Английский (EN).
   - Приоритет: `localStorage['lang']` -> `navigator.language` (если начинается с `ru` -> RU, иначе EN) -> default: EN.
2. **Темы:** Dark / Light.
   - Приоритет: `localStorage['theme']` -> `prefers-color-scheme` -> default: Dark.
   - Защита от мигания (инлайн-скрипт чтения темы в `<head>`).
3. **Кастомизация:** В настройках доступен выбор цвета светлячка (сохраняется в `localStorage`).

---

## 7. Адаптивность и UI Layout
Поддержка экранов 16:9, 21:9, 9:16 и складных квадратных устройств (~4:3).
1. **Header (Верх):**
   - Название игры / номер дня.
   - Правый блок кнопок:
     1. `[?]` Помощь (инструкция зависит от определенного типа устройства: ПК vs Тач).
     2. `[Stats]` Статистика (прошлые результаты, визуализация маршрута забега).
     3. `[Settings]` Шестеренка (смена языка, темы, цвета светлячка, звуков).
2. **Центр:** `<canvas>` лабиринта, пропорционально масштабируемый (`aspect-ratio` сохраняется, вписывается через `object-fit: contain`).
3. **Тайм-сплиты:**
   - **Десктоп:** Панель сплитов справа от лабиринта (с возможностью свернуть).
   - **Мобилки:** Полупрозрачный компактный HUD поверх верхней/боковой части канваса.
4. **Footer:** Юридические данные, Privacy Policy, ссылка на GitHub.

---

## 8. Данные забега и Шеринг
1. **Запись трека (Ghost/Replay):**
   - Во время забега с частотой 10 Гц сохраняется массив координат `[x, y, timestamp]`.
   - В окне статистики отображается миникарта с отрисовкой всего пути игрока за выбранный раунд.
2. **Шеринг (Wordle-style):**
   - Кнопка «Поделиться» копирует текст в буфер:
     ```text
     DailyMaze #XX ⏱️ 0:42.15
     Сплиты: 🟢 🟢 🟡 🏁
     [Ссылка на игру]
     ```
```
